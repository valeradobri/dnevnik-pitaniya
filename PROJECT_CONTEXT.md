## 1. НАЗНАЧЕНИЕ И ВИДЕНИЕ ПРОДУКТА

**Дневник** — современный, премиальный персональный ассистент по питанию, контролю веса и формированию здоровых привычек. Приложение создается как полноценный, коммерчески надежный продукт для ежедневного персонального использования с последующей публикацией в Google Play Store.

### Ключевые ценности:
1. **Здоровая психология и забота**: Отсутствие чувства вины, запрет на опасные дефициты калорий (не менее 1200 ккал для женщин, 1500 ккал для мужчин), учет естественных суточных колебаний веса (сглаживание тренда), фокус на стабильности привычек, а не на голодании.
2. **Local-First надежность**: Все данные сохраняются на устройстве в реляционной базе данных Drift (SQLite). Приложение полноценно функционирует без интернета. Архитектура готова к бесшовной синхронизации с Supabase в будущем.
3. **Скорость и эргономика**: Ввод приема пищи за 3-4 касания, быстрые пресеты для воды (+150, +250, +500 мл), быстрый поиск по верифицированной базе продуктов, копирование приемов пищи.
4. **Визуальное совершенство (Material 3 + Human Interface)**: Теплый светлый и глубокий контрастный темный режимы, выверенная изумрудно-коралловая палитра, адаптивные графики, мягкие микро-анимации, отсутствие перегруженности.

## 4. СХЕМА БАЗЫ ДАННЫХ (DRIFT / SQLITE)

Схема нормализована, типизирована и оптимизирована для реактивных выборок со связями и внешними ключами.

### Таблицы:
1. **`user_profiles`**:
   - `id`: Int (PK)
   - `name`: Text
   - `birth_date`: DateTime
   - `gender`: Text (`male`, `female`)
   - `height_cm`: Real
   - `current_weight_kg`: Real
   - `target_weight_kg`: Real
   - `activity_level`: Text (`sedentary`, `light`, `moderate`, `active`, `very_active`)
   - `goal_type`: Text (`lose_weight`, `maintain`, `gain_weight`)
   - `weekly_rate_kg`: Real (дефолт 0.5 кг/неделю)
   - `target_calories`: Int (рассчитанный или кастомный)
   - `target_protein_g`: Real
   - `target_fat_g`: Real
   - `target_carbs_g`: Real
   - `target_water_ml`: Int
   - `created_at`, `updated_at`: DateTime

2. **`food_products`**:
   - `id`: Int (PK, AutoIncrement)
   - `name`: Text (Index)
   - `brand`: Text (Nullable)
   - `calories_per_100g`: Real
   - `protein_per_100g`: Real
   - `fat_per_100g`: Real
   - `carbs_per_100g`: Real
   - `fiber_per_100g`: Real (Nullable)
   - `category`: Text (крупы, мясо, молочка, фрукты и т.д.)
   - `source_type`: Text (`verified`, `user`, `ai`, `open_food_facts`)
   - `barcode`: Text (Nullable, Unique Index)
   - `is_favorite`: Bool (Default: false)
   - `serving_size_g`: Real (Default: 100.0)
   - `created_at`: DateTime

3. **`diary_entries`**:
   - `id`: Int (PK, AutoIncrement)
   - `meal_type`: Text (`breakfast`, `lunch`, `dinner`, `snack`)
   - `food_product_id`: Int (FK -> `food_products.id` on delete cascade)
   - `custom_name`: Text (снимок названия продукта)
   - `grams`: Real
   - `calculated_calories`: Real
   - `calculated_protein`: Real
   - `calculated_fat`: Real
   - `calculated_carbs`: Real
   - `entry_date`: DateTime (Date-only Index для выборки дня)
   - `timestamp`: DateTime
   - `notes`: Text (Nullable)

4. **`water_entries`**:
   - `id`: Int (PK, AutoIncrement)
   - `amount_ml`: Int
   - `entry_date`: DateTime (Index)
   - `timestamp`: DateTime

5. **`weight_entries`**:
   - `id`: Int (PK, AutoIncrement)
   - `weight_kg`: Real
   - `entry_date`: DateTime (Unique Index)
   - `notes`: Text (Nullable)
   - `timestamp`: DateTime

6. **`recipes`** и **`recipe_ingredients`**:
   - Хранение названия, описания, времени приготовления, категорий, количества порций, и ссылок на ингредиенты из `food_products` с граммовками. Автоматический пересчет БЖУ на порцию.

7. **`meal_plans`** и **`shopping_items`**:
   - Недельный календарь плановых блюд и автогенерация корзины покупок с чекбоксами выполнения.

8. **`achievements`** и **`user_achievements`**:
   - Система бейджей и поощрений за регулярность без демотивации при пропусках.

9. **`app_settings`**:
   - Настройки интерфейса, темы, времени напоминаний, единиц измерения.

## 5. ДИЗАЙН-СИСТЕМА И UX-ПРИНЦИПЫ

### Цветовая палитра:
- **Primary Accent**: Изумрудно-зеленый (`#059669` / `#10B981`) — символизирует здоровье, свежесть и баланс.
- **Secondary Accent**: Мягкий кораллово-оранжевый (`#F97316` / `#FB923C`) — фокус на энергии, белках и углеводах.
- **Background (Light)**: Теплый мягкий фон (`#FAF9F6` / `#F4F4F6`), не бьющий в глаза белизной.
- **Surface (Light)**: Чистый белый (`#FFFFFF`) со скруглением 18–24px и диффузной легкой тенью (`rgba(0,0,0,0.04)`).
- **Background (Dark)**: Глубокий темный графит (`#121417`), карточки (`#1E2228`).
- **Макронутриенты**:
  - Белки: Сине-фиолетовый акцент (`#6366F1`)
  - Жиры: Теплый золотистый янтарь (`#F59E0B`)
  - Углеводы: Бирюзовый / Коралловый (`#14B8A6` / `#EC4899`)
  - Вода: Чистый аквамарин (`#0EA5E9`)

### Навигационная карта (Bottom Navigation Bar):
1. **Главная (Dashboard)**: Суточный статус калорий, БЖУ, прогресс воды, последние приемы пищи, кнопка быстрого добавления.
2. **Дневник (Diary)**: Полная хроника питания по приемам (Завтрак, Обед, Ужин, Перекусы), выбор даты, добавление граммов.
3. **Питание (Nutrition)**: Рецепты, недельный план питания, список покупок в магазин.
4. **Статистика (Analytics)**: Интерактивные графики веса, баланса макросов, дефицита/профицита за 7, 30 и 90 дней.
5. **Профиль (Profile)**: Персональные параметры, цели, настройки напоминаний, экспорт базы данных.
- **Центральный плавающий FAB**: Быстрое всплывающее меню: «Добавить блюдо», «Записать воду», «Внести вес».

## 7. РЕШЕНИЯ И ОГРАНИЧЕНИЯ (DECISION LOG)

1. **Local-First vs Cloud**: Принято решение строить полнофункциональный MVP на базе Drift (SQLite). Это гарантирует мгновенную работу, приватность персональных данных пользователя и нулевые затраты на сервера.
2. **Медицинская безопасность**:
   - Строгий запрет на дефицит ниже базового метаболизма (BMR) без явного предупреждения.
   - Минимальный порог калорий: 1200 ккал/день (женщины), 1500 ккал/день (мужчины).
   - Формула Миффлина-Сан Жеора используется как международный золотой стандарт клинической диетологии.
3. **Психологический комфорт**:
   - Никаких красных штрафных баннеров при переборе калорий. Вместо этого — мягкое информирование: «Сегодня вы съели немного больше запланированного — это абсолютно нормально в рамках долгосрочного баланса».
   - Учет колебаний веса (задержка воды, гликоген) через отображение скользящей средней линии тренда.
