# Дневник — Персональный ассистент по питанию и привычкам

[![Flutter](https://img.shields.io/badge/Flutter-3.x+-02569B?logo=flutter&logoColor=white)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.x+-0175C2?logo=dart&logoColor=white)](https://dart.dev)
[![Architecture](https://img.shields.io/badge/Architecture-Feature--First%20Clean-emerald)](https://riverpod.dev)
[![Database](https://img.shields.io/badge/Database-Drift%20%2F%20SQLite-003B57?logo=sqlite&logoColor=white)](https://drift.simonbinder.eu)
[![License](https://img.shields.io/badge/License-Proprietary-blue)](#)

Современное, эстетичное и надежное мобильное приложение на Flutter для осознанного контроля питания, расчета калорий и БЖУ, отслеживания веса и формирования здоровых привычек. Полностью на русском языке, ориентировано на платформу Android с возможностью кроссплатформенного расширения на iOS.

---

## 🌟 Ключевые возможности

- 🥗 **Умный дневник питания**: Разбивка на завтрак, обед, ужин и перекусы, мгновенный поиск продуктов, ввод граммовок за 3 клика.
- 🎯 **Персонализированные нормы**: Клинически выверенный расчет базового обмена веществ (BMR по формуле Миффлина-Сан Жеора) и TDEE с учетом активности и целей.
- 💧 **Трекер гидратации**: Учет выпитой воды с удобными пресетами (+150 мл чашка, +250 мл стакан, +500 мл бутылка).
- ⚖️ **Контроль динамики веса**: Интерактивные графики сглаженного тренда с устранением суточных водных колебаний.
- 📖 **Книга сбалансированных рецептов**: Автоматический пересчет БЖУ на порцию и перенос блюда в дневник в один тап.
- 🛒 **Недельное планирование & Список покупок**: Календарь питания и автогенерация корзины продуктов.
- 🧠 **Этичный AI-помощник**: Советы по замене продуктов, генерация блюд из остатков в холодильнике, без опасных диет.
- 🛡️ **Local-First & Приватность**: Все данные хранятся локально в типобезопасной базе SQLite (Drift) без обязательного облака.

---

## 🛠️ Технологический стек

- **Ядро**: Flutter 3.x+ / Dart 3.x+ (Sound Null Safety)
- **State Management**: [Riverpod](https://riverpod.dev) (`flutter_riverpod`, `riverpod_annotation`)
- **Навигация**: [GoRouter](https://pub.dev/packages/go_router) с вложенными независимыми стеками `StatefulShellRoute`
- **База данных**: [Drift](https://drift.simonbinder.eu) (реактивная типизированная ORM над SQLite)
- **Графики**: [fl_chart](https://pub.dev/packages/fl_chart)
- **Хранилище настроек**: `shared_preferences` и `flutter_secure_storage`
- **Дизайн**: Material 3 с индивидуальной дизайн-системой (шрифт Inter, изумрудно-коралловая гамма)

## 📂 Структура проекта

```text
lib/
├── app/                  # Инициализация приложения, роутер, темы, глобальные провайдеры
├── core/                 # Drift БД, общие утилиты (формулы КБЖУ), ошибки, UI-примитивы
└── features/             # Независимые фиче-модули (Presentation, Domain, Data)
    ├── onboarding/       # Первичная анкета и расчет целей
    ├── dashboard/        # Главный экран с кольцом калорий и макросами
    ├── diary/            # Дневник приемов пищи и выбор порций
    ├── food_database/    # Каталог проверенных продуктов и свои блюда
    ├── water/            # Трекер гидратации
    ├── weight/           # Модуль взвешивания и динамики
    ├── recipes/          # Каталог рецептов
    ├── meal_planner/     # Планировщик и корзина покупок
    ├── analytics/        # Графика и тренды
    ├── gamification/     # Серии и здоровые достижения
    ├── ai_assistant/     # Модуль AI-советов и распознавания
    ├── notifications/    # Локальные напоминания
    └── profile/          # Профиль и настройки
```
